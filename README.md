# SISY Space - Your Safe Place to Begin

Landing page for [sisy.space](https://sisy.space) - a warm, gentle entry point for women ready to share their expertise with the world.

## What is SISY Space?

SISY Space addresses impostor syndrome directly and warmly. Inspirational stories, a self-assessment quiz teaser, gentle onboarding flow, curated resources from sisy.study, an affirmation section, and community connection points.

## Tech Stack

- [Hugo](https://gohugo.io) static site generator (v0.142.0 extended)
- Hosted on GitHub Pages with custom domain
- Inter + Playfair Display fonts
- Lucide icons

## Local Development

```bash
hugo server -D
hugo --gc --minify
```
